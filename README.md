# Ranga Rasodaya 2026 — Welcome Page

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy
Upload this folder to GitHub Pages, Netlify, or Vercel.

## QR workflow
1. Deploy the site.
2. Copy the final public URL.
3. Put that URL into a QR generator.
4. Replace the demo QR on the physical poster with the generated QR.
5. Test the QR using at least two phones before printing.

The QR should point to the deployed `index.html` URL.
